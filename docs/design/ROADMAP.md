## Deploy and test (ready, not run)

Everything above marked "not deployed" ships in one restart: `trinitycore-tracking/perf/p0_soak/RUNBOOK.md` and `soak.sh` (a worldserver build with all of it is in `build/`, md5 differs from the live one). The script checks nobody is online, backs up the binary and both confs, runs about an hour with 4 map threads and `Debug.ForceActive = 100`, always restores the confs and the restart policy, and keeps the new binary only if the run was clean. Then the in-game innkeeper test. Re-runnable audits: `trinitycore-tracking/perf/audits/enemy_zone_audit.sh` (baseline 29 of 750) and `armor_audit.sh` (baseline 108 of 4,635). Kill switches without a rebuild: `Playerbots.Spawn.Evict`, `Gear.ClassArmorOnly`, `Mounts.RacialGrant`, `Rpg.HopChance`, `Rpg.GreetEmotes`.

## Dependencies

P0 → P0b → P1 → P2 → P2b → (P3, P4 in either order) → P5 → P6. P5 can start after P2 if perf becomes the blocker.

## Out of scope (v1 and v2 unless reopened)

Combat quests beyond kill-only, LLM chat, flying/skyriding, Exile's Reach, AH posting beyond grey/white (no valuation logic), taxi node discovery, guild bank/tasks, rated PvP tuning, per-boss puzzle mechanics without hints.
